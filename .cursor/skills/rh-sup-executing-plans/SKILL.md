# 执行计划（Executing Plans）

## 概述

加载计划、批判性审阅、执行全部任务，完成后汇报。

**开始时声明：**「我正在使用 executing-plans 技能来实现本计划。」

**说明：** 告知你的协作伙伴：在**支持子代理**的平台上，Superpowers 类工作流效果更好（如 Claude Code 或 Codex）。若可用子代理，应改用 **`rh-sup-subagent-driven-development`**，而非本技能。

## 流程

### 步骤 1：加载并审阅计划

1. 阅读计划文件
2. 批判性审阅 — 找出对计划的疑问或顾虑
3. 若有顾虑：在开始前向协作伙伴提出
4. 若无顾虑：创建 TodoWrite 并继续

### 步骤 2：执行任务

对每个任务：

1. 标为 `in_progress`
2. 严格按计划中的每一步执行（计划应为小步）
3. 运行计划中规定的验证
4. 标为 `completed`

### 步骤 3：完成开发

全部任务完成并验证后：

- 声明：「我正在使用 **finishing-a-development-branch** 技能来完成本工作。」
- **必选子技能：** 使用 **`rh-sup-finishing-a-development-branch`**
- 按该技能验证测试、展示选项并执行所选路径

## 何时停止并求助

**出现以下情况时立即停止执行：**

- 遇到阻塞（缺依赖、测试失败、指令不清）
- 计划有关键缺口导致无法开始
- 不理解某条指令
- 验证反复失败

**宁可澄清也不要猜测。**

## 何时回到更早步骤

**在以下情况回到审阅（步骤 1）：**

- 伙伴根据你的反馈更新了计划
- 根本做法需要重新考虑

**不要硬闯阻塞** — 停下并提问。

## 牢记

- 先批判性审阅计划
- 严格按计划步骤执行
- 不要跳过验证
- 计划要求引用技能时照做
- 受阻时停下，不要猜
- **未经用户明确同意，不要在 main/master 分支上开始实现**

## 衔接

**所需工作流技能：**

- **`rh-sup-using-git-worktrees`** — 必选：开始前建立隔离工作区
- **`rh-sup-writing-plans`** — 生成本技能所执行的计划
- **`rh-sup-finishing-a-development-branch`** — 全部任务完成后收尾
